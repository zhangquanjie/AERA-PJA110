# AERA Recovery device tree for OnePlus Ace 2 Pro (PJA110)

Targets AERA 16.0 and the crDroid Android 17 20261118 firmware baseline.
The resulting recovery image must be used with the paired
`vendor_boot-20261118-recovery-fixed.img`; the vendor boot ramdisk provides the
tested DRM/touch module ordering required by this device.
